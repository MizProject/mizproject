# Welcome to the MizProject's GitHub Organization Page

This organization Believes in freedom of customizability and reliability of software and hardware that we commonly use. This group is dedicated to creating and sharing open-source projects that are practical and sets limits beyond the OEM's set standard

MizProject is commited to support Open-Source by Publicly sharing changes and modifications on the work that's under the OSS agenda. 

And also committed to try, learn and adapt new changes of the whole software environment
